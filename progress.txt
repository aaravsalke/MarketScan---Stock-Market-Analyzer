HOW TO RUN
----------
From the MarketScan folder:

    pip install -r requirements.txt
    python app.py

Menu:
    1 = Stock search (ticker OR company name)
    2 = Technical analysis (20-day MA, 50-day MA, RSI, chart)
    3 = Company news (title, source, date, link; type a number to open)
    Q = Quit

If several companies match a name, pick a number. Type C to cancel the list.
On news, type an article number to open it, or press Enter to go back.

IMPORTANT FUNCTIONS
-------------------
search_securities(query)
    Yahoo name/ticker search. Keeps EQUITY and ETF only.

choose_security(query) / ask_for_chosen_security() in app.py
    Exact ticker match wins. One match auto-selects. Many matches -> numbered list.

fetch_stock_quote(ticker)
    Quote dictionary. Call only after a real search match.

fetch_price_history(ticker)
    Two lists: dates and closing_prices.

calculate_moving_average / calculate_rsi
    Plain loops. None until enough days exist.

show_technical_charts(...)
    Two stacked plots. Close the window to return to the menu.

fetch_company_news(ticker, max_articles)
    Returns a list of dicts: title, source, published_date, url.

_parse_yahoo_article(item)
    Yahoo nests fields under item["content"]. This helper flattens them.

open_article(article) in app.py
    Prints the URL, then webbrowser.open(url).

KNOWN LIMITATIONS
-----------------
- RSI is the simple classroom formula, not Wilder's smoothed RSI.
- Chart uses plt.show(). Menu waits until the chart is closed.
- Search can return the same company on other exchanges (AAPL and AAPL.TO).
- Yahoo news is not always 100% about that one ticker. You may see
  related market / tech videos mixed in.
- webbrowser.open works on a normal computer. In Colab, use the printed link.
- This is not financial advice.
